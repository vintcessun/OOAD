为什么叫结构化设计？三层怎么分？

这一阶段按功能过程分解：Controller 接 HTTP 参数与统一响应，Service 写校验、业务流程和事务，Mapper 负责 MySQL/Redis 的数据访问；依赖只能从上往下。这里的 Mapper 是 JPA 接口名称，不代表使用 MyBatis。
