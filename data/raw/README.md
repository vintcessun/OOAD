# 原始数据

课程提供的三份基础数据放在此目录：

| 文件 | 内容 | 规模 |
|---|---|---|
| `市政公司部门信息表.xlsx` | 部门名称、部门经理、上级部门 | 111 行，三层单根 |
| `市政公司员工信息表.xlsx` | 姓名、用户名、分公司、部门、岗位、电话 | 10000 行 |
| `市政公司应用软件功能权限清单.xlsx` | 软件系统/功能模块/功能点 × 5 个角色 | 359 个功能点 |

## ⚠️ 这些文件不入库

员工信息表含**一万条真实姓名与手机号**。`.gitignore` 已排除 `data/raw/*.xlsx`。

组员需自行从课程网站下载并放入本目录，导入脚本会从这里读取。

## 导入

导入规则见 [`../docs/03-database.md`](../docs/03-database.md) §5，需求编号 `RBAC-REQ-ORG-005`。

导入会产出**异常报告**，列出数据疑点（见 `../docs/01-srs.md` 附录 C）。该报告是检查时的展示材料之一。
