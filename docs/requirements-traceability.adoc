== 新旧验收映射

RBAC0 与 RBAC1 的业务范围已有变化。以下映射供迁移旧用例时查阅，替代后的验收仍覆盖原安全目标。

[cols="2,4",options="header"]
|===
|RBAC0 的验证点 |RBAC1 验收落点
|公司隔离、部门数据范围 |ID-01/06、ORG-01/04、ROLE-06。验证目标系统隔离、组织子树管理、部门直接准入及跨边界读写拒绝。课程对象权限由课程后端验证。
|资源与动作、菜单、本人范围 |RES-01～04、EXT-05。验证菜单和按钮权限、独立 API 操作权限、显式映射与服务端默认拒绝。
|角色权限并集与撤权 |ROLE-02～04、NFR-03。验证同系统继承、多来源、停用路径切断及跨实例撤权。
|认证、越权与账号保护 |ID-02/03/07、ROLE-06/07、NFR-02。验证错误凭据、账号状态、令牌撤销、授权上界和最后有效超级管理员保护。
|独立事务成功审计 |AUD-01/03/05。验证业务与成功记录同事务、适用的拒绝记录独立提交，以及重试幂等和故障回滚。
|===

两种后端设计的六组对照场景见 link:final-design.adoc[最终设计]。S01 覆盖继承验环，S02 覆盖部门准入与指派，S03 覆盖有效权限，S04 覆盖课程代理，S05 覆盖审计幂等，S06 覆盖业务与成功审计同事务。
