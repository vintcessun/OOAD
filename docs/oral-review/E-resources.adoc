== 预填调用链：阅读后核对，不代替结论

资源配置：对应Controller → Management/Resource事务脚本，或Directory/Resource应用服务→ResourcePolicy→ResourceRepository→JPA；版本/审计协作。

用户菜单：当前身份/有效UI权限 → menus或ResourcePolicy.visible → 裁剪树；父容器展示不能赋予子按钮。

入口覆盖：OAS → RouteRegistry/OperationContract → MVC路由/DB目录核验；网关可信method/path → operationId → D的中心决定 → 原课程Service对象规则。

课程私有投影：可信Bearer + 服务密钥 → API-only/ROLE_受控身份；lookup再验TEC/admin；公开边缘阻断私有路径。

== 主审检查项

* [ ] 两类权限同名也按system+kind定位，缺引用404且不得生成意外元数据。
* [ ] 菜单树、BUTTON父约束、停用父节点、环/孤儿、排序及可空字段PATCH。
* [ ] 映射多对多但只追踪；API策略独立，中心受保护路由不得弱化或改成不存在路径。
* [ ] OAS、实际Controller和持久目录双向对应，不能只做正向匹配；新受保护路由默认拒绝。
* [ ] 私有authorities不是把auth/me变成完整API能力清单；服务密钥和Bearer缺一不可，最小身份字段不泄露凭据。
* [ ] copyCourse全局teacher与本课程组长/非组长CC分别负责什么；课程对象级403保留原职责。
* [ ] 辅助检查前端各页/按钮符合需求，隐藏后直接HTTP仍拒绝；不深挖样式实现。
* [ ] 同前端MODULE切换、七服务、网络/secrets、镜像/报告身份、本地与外部证据分界；不执行部署。

== 数据与职责

sys_system、sys_permission、sys_ui_resource、sys_api_operation、sys_ui_api_mapping；种子按系统/角色/权限码对照，不能把菜单/API映射当赋权。

E汇总API、页面和部署证据，不代替其他成员读自己接口或页面；与D互审中心决定。课程完整上游缓存不进入逐文件主审清单，保留老师系统边界和来源即可。

== 必须准备的场景

* 正常：系统/权限资源登记、菜单显示、API映射、同前端切两后端。
* 等价/边界：有UI无API、有API无UI、同字符串不同kind、缺引用、空映射、显式null和省略。
* 异常：中心路由弱化、未知/歧义路由、假operationId头、服务密钥错误、中心超时、全局允许后课程对象拒绝。
