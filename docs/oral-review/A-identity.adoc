== 预填调用链：阅读后核对，不代替结论

structured：AuthController.login → AuthenticationService.login → authz.lock/凭据/失败计数/审计 → 事务返回 → TokenService.issue。失败结果要先结束事务，再抛凭据错误。

DDD：IdentityController.login → IdentityApplicationService.login → LoginAttemptApplicationService.attempt → lockLogin/LoginAttemptPolicy/saveLoginState/审计/TokenProvider → 外层失败响应。

后续请求：两版实际拦截器/RestSupport → 验证签名声明 → 实时身份/系统/tokenVersion/jti → D的授权；退出jti持久化、改密tokenVersion与用户状态联查。

== 主审检查项

* [ ] 逐项解释sub/aud/iss/kid/iat/exp/jti/tokenVersion，不能从JWT角色声明推导当前权限。
* [ ] 追踪5次失败、锁到期、成功清零、并发失败和不存在账号；读事务边界，不能仅背策略常量。
* [ ] 退出204无body；Redis丢失后MySQL撤销仍有效；改密及停用恢复不能复活旧token。
* [ ] 核对本人输出只返回当前aud的有效课程角色码和 UI 权限，密码哈希不出VO。
* [ ] 选择一次页面动作，指出两版API/应用/基础设施日志与事务提交的差别；代理自调用不虚称必被AOP捕获。
* [ ] 核对生产配置、bootstrap、错误映射与密钥轮换，注意两实现阈值和编码的差异。

== 必须准备的场景

* 正常：登录两个目标系统，核对裸响应和同一subject；退出与改密。
* 等价/边界：正确/错误/不存在/停用账号、单aud/多aud、过期/未来iat、密码长度和初始化参数。
* 异常：撤销持久化、未知kid、错误签名、DB/审计失败；说明会提交和会回滚的事实。
