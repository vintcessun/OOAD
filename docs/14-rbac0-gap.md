## 1. 需求清单逐条对照

| 需求 | 状态 | 依据 |

| Jacoco 白盒测试，每个功能都有测试 | ✅ | 69 个测试，行 97.5%、分支 84.1%；45 个接口全部经 HTTP 调用过（[09](09-test-plan.md)） |

### 1.2 功能与业务

| 需求 | 状态 | 依据 |
|---|---|---|
| 登录、鉴权两个场景 | ✅ | `/auth/*`、`/authz/check`；T01、T02、T17；T04–T07 |
| 一个用户属于一个部门，但可以有多个部门的权限 | ✅ | 指派带适用部门 `scope_dept_id`，作用域逐条判断；T07、T07b、T15 |
| 临时用户，没有工号、电话等员工信息 | ✅ | `user_type = TEMPORARY`，必须有到期时间；T03 |
| 按分公司、部门、员工级别批量权限管理 | ✅ | `/assignments/batch`、`/batch-revoke`，ATOMIC / PARTIAL；T16、`batchAssignByCompanyAndDepartmentThenRevoke`；真实数据一次批量 10,000 人 |
| 多个公司、大量部门、上万员工、多权限域、多业务系统 | ✅ | `sys_company`；真实数据 111 部门、10,000 人、18 个业务系统；多公司隔离 T19（第二家公司为测试数据） |

### 1.3 管理员

| 需求 | 状态 | 依据 |
|---|---|---|
| 超级管理员越过权限引擎 | ✅ | 判定 3.3 步；账号必须有效；T11 |
| 管理员管理自身和以下层级员工的权限 | ✅ | 管理范围 = 适用部门子树；Service 按目标对象所在部门判定；T08、T09；另有授权上界（不能授出自己没有的权限，「本人」范围也比较）T10、T10b |
| 移除管理员权限，不导致分配的权限级联删除 | ✅ | 只删该指派，`granted_by` 只是审计属性；T14 |
| 管理员可以自己撤销自己权限（10/15 课堂要求） | ✅ | 回收自己的指派不查管理范围，最后一个超级管理员除外；个人中心有回收按钮；T14b（[12 R-16](12-design-log.md)） |
| 用户编号预留一段给内部用户（10/15 课堂要求） | ✅ | 1–9999 内部账号（`root`、业务系统账号），员工与临时用户从 10000 起；V3 迁移；`internalAccountsUseTheReservedIdRange`（[12 R-17](12-design-log.md)） |
