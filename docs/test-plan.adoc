== 隔离和失败关闭

* 专用实例为loopback MySQL13306、Redis16379；课程测试另用13316。不得连接生产、旧rbac_test或共享Swarm数据卷。
* structured集成测试在Spring启动前固定并校验专用datasource/Flyway，精确rbac1_structured_test；自身稳定UUID cache namespace，只清自身前缀，不再清structured:*。
* DDD集成库为rbac1_ddd_test；JUnit测试profile从TEST_DB_PASSWORD读取专用口令，不进入生产jar。环境白名单不继承外部Spring/JVM覆盖。
* shared只创建rbac1_contract_<实现>_<时间戳>_<随机>，E2E只创建rbac1_e2e_<实现>_<时间戳>；不得接受调用者指定既有库。
* 子JVM使用本次私有临时jar副本，避免Windows锁住target；只终止自有且仍存活的child，等待退出后才清自建库。端口冲突安全拒绝，不杀已有进程。
* datasource/Flyway/Redis/namespace/keys经canonical Spring JSON固定，只加载classpath配置；不因设置一个DB_URL就假定两实现都读取它。
* 私钥、口令、服务key、有效JWT不进入Git/报告/日志；测试为合成fixture，无真实人员。只用有权限的测试凭据。
* JAVA_HOME严格21、Node22+；缺工具/依赖/readiness或清理错误属于ENVIRONMENT_BLOCKED，不冒称业务RED或PASS。

== 正确执行顺序

外部真实HTTP覆盖必须先收集，再应用原门槛；不能先在未完整收集时把verify失败当成功，也不能降低阈值。

[source,shell]
----
# 明确JAVA_HOME为JDK21；先确认专用MySQL/Redis与建库权限。
bash tools/install-clonefactory.sh
python tools/generate-rbac1-contract.py --check
python tools/generate-rbac1-contract-test.py
node --test tools/*.test.mjs
./mvnw clean package                       # 正常执行全部JUnit，不跳过
source deploy/full-jacoco-agent.sh          # 官方agent和官方dump CLI
export ACCEPTANCE_DB_PASSWORD='<专用测试实例凭据>'
(cd tools/acceptance && npm ci && npm test && npm run acceptance)
./mvnw verify -DskipTests                   # 合并exec、report、原check；不是跳过未跑JUnit
----

Windows的SIGTERM实际上终止进程、不执行Java shutdown hook，因此使用仅loopback的JaCoCo TCP agent，并在停止自有JVM前以官方CLI dump，要求文件非空。
每次JVM启动/重启选择新的私有agent端口，不能抢固定诊断端口或误dump其它进程。中间禁止clean破坏已收集exec。
最终部署gate同时要求真实Surefire数量、0失败/错误/跳过、全模块verify成功、shared全部成功及当前jar等于实际运行快照，不能凭一个skipTests成功日志伪造测试。

前端：`npm ci`、`npm run typecheck`、`npm run test:coverage`、`npm run build`，分别以E2E_MODULE=rbac-structured/rbac-ddd执行`npm run e2e`。
仅允许显式JAVA_HOME，PW_CHROMIUM可指定浏览器；不接受绕过JDK核验的任意JAVA_BIN。
课程、UML和本地部署使用各自目录的可复现脚本，状态分别记账。

== 关键矩阵

. DAG多父/传递/菱形、多来源、停用路径切断、同系统、自环/重复/并发拒绝及立即撤权。
. 对称反向并发允许任一请求合法先获锁，但两侧都须一成功一ROLE_CYCLE，SQL唯一边必须与成功请求方向一致；仅该隔离角色对按合法结果集比较，其它关系/顺序/version不去噪。
. 部门直接准入（含超级管理员）、子树管理、跨部门调动清空本人的角色指派（含目标部门允许的角色）、同部门请求保留指派。调动测试同时验证共享角色权限。
. 操作者变更前上界冻结；空权限SUPER_ADMIN仍是特殊能力，非超管不能编辑/指派/继承；最后有效管理员不可间接锁死。
. RS256/issuer/aud/kid/iat/exp/签名/轮换、单aud无角色claim、状态/tokenVersion、跨JVM注销及Redis清理后仍拒绝。
. UI/API独立、映射不赋权、同system/kind引用缺失404且不得写入非法元数据，未知路由默认拒绝。
. 角色启停与资料编辑使用不同 API 权限。双后端以仅有编辑权限及仅有启停权限的操作者分别验证成功和拒绝，拒绝后核对角色资料和状态。V3 迁移测试验证 V2 自定义编辑角色未获新权限。
. 模拟/解释验证UI/API、错误组合、停用目标200 false USER_DISABLED且有效管理员不被踢出。
. 七个教师裸/auth操作、两私有投影最小字段与双凭据、网关可信路由/固定上游/拒绝身份头和URL伪造；中心非200不得进入课程。
. 审计UUID/四事件/前缀/500字/安全JSON；同键串行并发同id、跨主体/系统异体拒绝；业务与SUCCESS同事务、trigger故障真实回滚，DENIED独立。
. 两实例预热L1/L2后撤权、确定交错版本重算/持续变化503、10,000合成用户数据库分页、日志无fixture秘密。
. 同一Vue前端连接两套真实后端进行桌面 Chromium 测试。TLS、私网、secrets、镜像一致性与本地受控切换分别验证。

旧多公司/scope/selfOnly预期按link:requirements.adoc[映射]替换，仍适用的认证/越权/事务/缓存/保护/保密断言保留，不加skip伪绿。
中心与课程跨库同步HTTP不是分布式事务；同UUID有限重试及未确认错误如实保留，不以Outbox/MQ掩盖。

== 真实失败保留

初期plain jar、CHAR/TINYINT实体校验、缺测试口令、Redis调度超时及固定agent端口冲突均如实记录为环境/启动阻塞后修复。
新工具链浏览器首轮3/4：root登录POST200后三个身份请求pending，不能确证并行I/O致因。后改为有限等待四响应且各200/裸协议、保留页面全部断言，m22完整4/4；没有sleep/重试掩盖失败。
非法BUTTON缺父节点属于夹具错误；类型化引用404按真实OAS校正且增加DB不落非法记录断言；并发先获锁方向差异按受控合法结果集比较并增强落库方向断言。
原始RED/阻塞日志保留在仓库外；最终成功不抹去之前失败，不将“源码存在”或“重新命名错误”替代权限规则与真实落库证明。
